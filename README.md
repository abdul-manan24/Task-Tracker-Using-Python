# Task-Tracker-Using-Python
This is a simple CLI application that tracks day to day tasks.

User guide:

Add Task:
To add task write 'add' followed by task description in double quotes.
e.g. add "Buy groceries"

Delete Task:
To delete task write 'delete' followed by task_id.
e.g. delete 3

Update Task:
To update task write 'update' followed by task id then task description.
e.g. update 3 "Buy groceries and cook dinner"

List All Tasks:
To list all tasks write 'list'
e.g. list

List Done:
To list tasks that are done write 'List' followed by done.
e.g. list done

List In-progress:
To list tasks that are in-progress write 'list' followed by in-progress.
e.g. list in-progress

List to-do:
To list task that are to-do write 'list' followed by to-do.
e.g. list to-do

by default every task's status will be to-do to change the status use following commands.

Mark In-progress:
To mark a task in progress write 'mark-in-progress' followed by task id.
e.g. mark-in-progress 3

Mark Done:
To mark a task as done write 'mark-done' followed by task id.
e.g. mark-done 3
